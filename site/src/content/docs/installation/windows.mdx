ROK Battles is distributed on Windows as a signed installer.

## Choose a version

* <DownloadVersion type="windows-x86_64">Windows 64-Bit</DownloadVersion> - Recommended for most PCs with Intel or AMD processors
* <DownloadVersion type="windows-aarch64">Windows ARM</DownloadVersion> - For ARM-based devices such as Snapdragon systems

## Install

1. Download the installer that matches your CPU architecture.
2. Open the `.exe` file.
3. If Windows shows a security prompt, confirm that you want to continue.
4. Finish the installer and launch ROK Battles from the Start menu or desktop shortcut.

## Notes

* If you are not sure which version to pick, use `Windows 64-Bit`.
* The ARM build is only for Windows on ARM devices.
