---
title: Windows Startup Guide
---

Use these steps if you want ROK Battles to start automatically after you sign in to Windows.

## Open the install folder

1. Press `Win + R`.
2. Paste this path and press `Enter`:

```text
%LOCALAPPDATA%\ROK Battles
```

This is the default installation folder. If you installed ROK Battles somewhere else, open that folder instead.

## Create a shortcut

1. Click `rokbattles-tauri` once to select it.
2. Hold `Shift` and right-click `rokbattles-tauri`.
3. Click `Create shortcut`.

## Open your Startup folder

1. Press `Win + R`.
2. Paste this command and press `Enter`:

```text
shell:startup
```

## Move the shortcut

Drag the shortcut you created into the Startup folder.

## Verify startup is enabled

1. Open Task Manager.
2. Go to the `Startup apps` tab.
3. Confirm that ROK Battles appears and is enabled.
