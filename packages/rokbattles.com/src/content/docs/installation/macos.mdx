# Install on macOS

Choose **Apple Silicon** for a Mac with an M-series chip, or **Intel** for an Intel-based Mac. You can check your chip or processor in **Apple menu > About This Mac**.

<DownloadOptions platform="macos" />

## Install ROK Battles

1. Open the downloaded `.dmg` file.
2. Drag **ROK Battles** into your **Applications** folder.
3. Eject the disk image when the copy finishes.
