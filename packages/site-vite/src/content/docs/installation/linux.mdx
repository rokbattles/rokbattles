# Install on Linux

ROK Battles is available as an **AppImage** or a **Debian package**. Choose x64 for Intel or AMD systems, or ARM64 for an ARM-based device.

<DownloadOptions platform="linux" />

## AppImage

The AppImage is a portable option. Download the matching build, then open a terminal in the folder where you saved it.

Make the downloaded file executable, replacing the filename below with your download's exact name:

```bash
chmod +x ROK.Battles___VERSION___amd64.AppImage
```

You can then open the AppImage from your file manager.

## Debian package

Use the `.deb` package on Debian, Ubuntu, or another Debian-based distribution. Open a terminal in the download folder and install it, replacing the filename with your download's exact name:

```bash
sudo apt install ./ROK.Battles___VERSION___amd64.deb
```

For ARM64, use the downloaded `arm64.deb` file instead.
