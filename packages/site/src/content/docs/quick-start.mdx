title: Quick Start

Use this page after you have already installed the desktop app.

If you still need installation instructions, see:

* [Windows installation](/docs/installation/windows)
* [macOS installation](/docs/installation/macos)
* [Linux installation](/docs/installation/linux)
* [SteamOS installation](/docs/installation/steamos)

## 1. Open ROK Battles

The app may launch automatically after installation. If it does not, open `ROK Battles` from your Start menu, Applications folder, or app launcher.

## 2. Connect your mailcache directory

On Windows and macOS, click Auto to find your `mailcache` directory automatically.

On Linux and SteamOS, or if automatic discovery does not find it, click Add and choose the `mailcache` folder manually.

## 3. Leave the app running

The desktop app watches your `mailcache` folder and uploads battle reports automatically while you play.

On Windows and macOS, closing the window can minimize the app to the tray so it keeps running in the background.
