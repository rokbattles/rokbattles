title: SteamOS
---

SteamOS does not install `.deb` packages directly. If you are using a Steam Deck or another SteamOS device, you can run the Debian build of ROK Battles through Distrobox inside a Debian-based container.

## What to use

Use the Debian package:

* <DownloadVersion type="linux-x86_64-deb">ROK Battles for Debian-based Linux</DownloadVersion>

## Install with Distrobox

1. Install [Distrobox](https://distrobox.it), or install BoxBuddy from the Discover store.
2. Create a Debian-based container such as Debian, Ubuntu, or Linux Mint.
3. Install the ROK Battles `.deb` package inside that environment.

## BoxBuddy

If you are using BoxBuddy, you can use the `Install .deb file` action instead of installing from the terminal manually.

After installation, ROK Battles should appear in the `View Applications` section in BoxBuddy, where you can launch it.

## Notes

* These steps are intended for Steam Deck and other SteamOS systems, where native `.deb` installation is not available.
* This workflow was contributed by a community member running ROK Battles on a Steam Deck.
