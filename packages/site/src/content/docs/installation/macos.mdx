ROK Battles is available for both Apple Silicon and Intel Macs.

## Choose a version

* <DownloadVersion type="darwin-aarch64">macOS Apple Silicon</DownloadVersion> - Recommended for M1, M2, M3, and newer Macs
* <DownloadVersion type="darwin-x86_64">macOS Intel</DownloadVersion> - For older Intel-based Macs

## Install

1. Download the disk image for your Mac.
2. Open the downloaded `.dmg` file.
3. Drag `ROK Battles` into your `Applications` folder.
4. Open the app from `Applications`.

## Notes

* If you are unsure which version to download, Apple Silicon covers the newer M-series Macs, while Intel is for older hardware.
