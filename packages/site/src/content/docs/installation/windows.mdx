# Install on Windows

Download the installer for your PC. Choose **x64** for Intel or AMD processors, or **ARM64** for Windows on ARM devices such as Snapdragon PCs.

<DownloadOptions platform="windows" />

## Install ROK Battles

1. Open the downloaded `.exe` file.
2. Follow the installer prompts.
3. Finish the installation. ROK Battles will be available from the Start menu.
